# CONCURRENTS LOU AME TAY — Analyse Aissatou (Fiche 02)

## 🔍 CARTOGRAPHIE DU MARCHÉ

### 1. MAFALIA
- **Focus** : Chaîne d'approvisionnement CHR (achats grossistes, centrales d'achat)
- **Force** : 132 restaurants équipés en 8 mois au Sénégal
- **Prix** : Sur devis
- **Faiblesse** : Ne couvre pas l'expérience client en salle, ni la commande à table, ni le KDS cuisine
- **Menace pour LAT** : 🟡 Faible (partenaire potentiel ou complémentaire)

### 2. SCANIFOOD
- **Focus** : Menu digital statique via QR code
- **Force** : Partenariat de visibilité avec Pizza Time Senegal
- **Prix** : Entrée de gamme
- **Faiblesse** : Pas de KDS cuisine interactif, pas de commande en direct avec Wave/OM
- **Menace** : 🟠 Moyenne

### 3. SPOON AFRICA
- **Focus** : Application mobile téléchargeable pour gestion restaurant
- **Force** : Présence sur plus de 100 restaurants en Côte d'Ivoire et Sénégal
- **Prix** : Moyen
- **Faiblesse** : Nécessite que le client télécharge une application sur l'App Store / Play Store
- **Menace** : 🟠 Moyenne

### 4. TAARIH
- **Focus** : Gestion financière & comptabilité administrative
- **Force** : Solution robuste pour la gestion de back-office
- **Prix** : Moyen
- **Faiblesse** : Zéro expérience client en salle, aucun menu digital pour les convives
- **Menace** : 🟡 Faible

### 5. SEN QR MENU
- **Focus** : Menus QR basiques et réservations
- **Force** : Jeune startup locale (2025)
- **Faiblesse** : Faible maturité technique, manque de support terrain
- **Menace** : 🟢 Très faible

### 6. FLIPDISH / GLORIAFOOD
- **Focus** : Géants SaaS internationaux
- **Prix** : ~15 500 FCFA/mois + commissions variables
- **Faiblesse** : Aucun support physique local, pas d'intégration native Wave/Orange Money directe
- **Menace** : 🟠 Moyenne

## 🏆 AVANTAGE CONCURRENTIEL LOU AME TAY
Lou Ame Tay est le **seul acteur "tout-en-un"** conçu pour l'Afrique de l'Ouest :
- **Expérience client** : Menu QR interactif, commande à table, paiement Wave/OM instantané
- **Gestion interne** : KDS brigade cuisine en temps réel, écran TV retrait, gestion des ruptures
- **Networking terrain** : Cartes digitales pour l'équipe, CRM de prospection commerciale
- **Support local** : Siège à Thiès, intervention terrain 30 min, hotline WhatsApp 7j/7
- **Ancrage culturel** : Interface et formation bilingues Français & Wolof
